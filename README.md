# 🚢 Sonar.io — Тактический морской бой

Интерактивная веб-игра в «Морской бой» с элементами футуристичного сонара, разработанная для инкубатора Нархоз.

## ✨ Особенности проекта
* **Умный алгоритм противника:** Бот не просто стреляет случайно, а умеет добивать раненые корабли (уровень «Сильный»).
* **Автоматическая расстановка:** Оптимизация UX — корабли расставляются по классическим правилам с защитным зазором в 1 клетку за секунду.
* **Авто-промахи:** При потоплении корабля вокруг него автоматически проставляются точки по канонам классической игры.
* **Современный стек:** React, Next.js, TypeScript, Tailwind CSS.
