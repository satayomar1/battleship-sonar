# Sonar.io — Tactical Battleship

**Sonar.io** — веб-версия «Морского боя» с одиночным режимом, умным ботом, приватным онлайн-мультиплеером и послематчевой тактической аналитикой.

Проект разработан для **Narxoz Incubator 2026**.

## Live Demo

**https://sonar-io.vercel.app**

Основные маршруты:

- `/` — Single Player
- `/multiplayer` — Private Multiplayer
- `/profile` — профиль и статистика

---

## Возможности

### Single Player

- Классический «Морской бой» на поле 10×10
- Автоматическая корректная расстановка флота
- Корабли не соприкасаются друг с другом
- Три уровня сложности бота
- Немедленный выстрел по клику на клетку
- Сохранение текущей партии в `localStorage`
- Победа / поражение и полный послематчевый разбор

### Smart Bot

Бот использует разные стратегии в зависимости от сложности:

- **Easy** — преимущественно случайный выбор клетки
- **Normal** — продолжает поиск после обнаруженного попадания
- **Hard** — использует более эффективную стратегию поиска и добивания кораблей

Игровая логика вынесена в отдельный TypeScript engine и покрыта автоматическими тестами.

### Real Multiplayer

Sonar.io поддерживает настоящий приватный multiplayer между разными устройствами через интернет.

Сценарий:

1. Игрок создаёт приватную комнату
2. Получает код приглашения
3. Второй игрок подключается по коду
4. Оба фиксируют свой флот
5. Матч переходит в режим `playing`
6. Ходы проходят через server-authoritative Supabase RPC
7. Состояние синхронизируется между клиентами
8. Сервер определяет победителя

Multiplayer проверен между компьютером и телефоном через production deployment.

### Tactical Debrief

После матча игрок получает реальный анализ своих действий:

- количество выстрелов
- количество попаданий
- точность
- лучшая серия попаданий
- heatmap выстрелов
- наблюдения по стилю игры
- тактические советы

Insights рассчитываются детерминированно на основе данных партии — без фиктивных AI-ответов.

### Profile & Statistics

Раздел `/profile` показывает сохранённую игровую статистику и историю результатов.

При доступном Supabase завершённые матчи синхронизируются с облаком; приложение также имеет локальный fallback.
